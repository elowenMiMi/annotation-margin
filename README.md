# 批注边栏 · Annotation Margin

划选任意文字 → 点浮动按钮 → 在右侧边栏直接写批注。批注以淡色底纹标在正文上，**悬停看浮窗、点击定位边栏**，边栏可随时收起。支持导出 Markdown / 公众号 HTML / PDF。

## 功能

- **划选即批注**：选中词 / 句 / 段，旁边浮出「＋ 为这段加入批注」，点它右侧边栏变成书写区，写完点「我写好了」（或 `Ctrl+Enter`）
- **右侧边栏**：按当前笔记分组，只显示这篇笔记的批注；右上角 `×` 收起
- **悬停预览**：鼠标停在批注文字上，浮窗显示内容（右上角 `×` 关闭）
- **点击定位**：点批注文字，边栏跳到对应条目；点边栏里的灰色引文，正文滚过去并闪一下
- **导出**：批注摘录 Markdown / 公众号 HTML（内联样式，可直接粘贴）/ PDF
- **跟随笔记**：笔记改名或移动时，批注自动跟过去；在 Obsidian 外部移动的，打开同名笔记时按「文件名 + 原文仍存在」自动回收

## 安装

- 社区插件市场搜索 **批注边栏**（上架后）
- 或用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 添加本仓库
- 手动：把 `main.js`、`manifest.json`、`styles.css` 放进 `<vault>/.obsidian/plugins/annotation-margin/`

## 用法

1. 阅读视图中划选文字
2. 点「＋ 为这段加入批注」
3. 右侧写内容 → 「我写好了」

建议给命令 **为选中文字添加批注** 绑个快捷键。

## 设置

| 项 | 说明 |
| --- | --- |
| 批注数据文件夹 | 默认 `_annotations`，每篇笔记一个 json |
| 悬停显示批注 | 开关 |
| 选中文字时显示浮动按钮 | 关掉后改用命令/快捷键 |
| 标记样式 | 底色高亮 / 虚线下划线 |

## 数据

批注存在 `<设置的文件夹>/ann-<路径哈希>.json`，**不写入笔记正文**，所以笔记保持干净。备份时连该文件夹一起拷走即可。

## 已知限制

- 只支持 Markdown 笔记；PDF / Word / 图片需要 Annotator 之类的插件
- 手动改动被批注的那句话，标记可能失效（边栏记录仍在，可删了重加）
- 实时预览里标记会随光标所在行刷新，阅读视图最稳
